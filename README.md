# Danik-tro Tap

## How do I install these formulae?

`brew install danik-tro/tap/<formula>`

Or `brew tap danik-tro/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "danik-tro/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
